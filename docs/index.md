# MATS Research Tooling Wiki

A practical guide to AI safety research tooling for [MATS](https://www.matsprogram.org/) fellows: which library, model, or compute setup to reach for, when *not* to use it, and the pitfalls to expect.

## Where to start

- **[Index: "I want to do X, use Y"](00_index.md)** — the decision table. Start here if you know roughly what you want to do.
- **[FAQ](FAQ.md)** — cross-cutting beginner questions (API keys, where to start, costs).
- **[Glossary](GLOSSARY.md)** — A–Z definitions of acronyms and concepts (CAA, GRPO, OOCR, RLAIF, …).
- **[Project shapes](21_project_shapes.md)** — what a paper-shaped project looks like in each area.

Use the search box (top right) for keyword lookup across every topic.

## Contributing

This wiki is maintained on GitHub at [`MATSResearch/compute_wiki`](https://github.com/MATSResearch/compute_wiki). Fellows and mentors are encouraged to contribute.

1. Click the **edit (pencil) icon** at the top of any page to jump straight to that file on GitHub.
2. Edit, then **propose the change as a pull request** (GitHub will offer to fork if you don't have write access).
3. A maintainer reviews and merges. Merges to `master` redeploy the site automatically.

When adding or editing a topic, follow the writing conventions in [`CONTRIBUTING.md`](https://github.com/MATSResearch/compute_wiki/blob/master/CONTRIBUTING.md) — these docs are also consumed by a retrieval system, so sections must be self-contained and keyword-dense.
